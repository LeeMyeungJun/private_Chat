# 모음 · 개인 채팅

MainPC에서 **모음 서버.lnk**를 더블클릭하면 **서버 관리창만 열립니다.** **모음 채팅.lnk**는 이미 실행 중인 서버의 채팅창만 열며 MainPC는 자동 입장합니다. 서버가 꺼져 있으면 종료 안내를 표시하고 서버를 실행하지 않습니다. 채팅창을 닫아도 서버와 다른 참가자의 대화는 계속 유지됩니다. 서버 관리창의 **채팅창 열기**로도 입장할 수 있습니다. **서버 관리창의 X 또는 서버 종료 버튼**을 누르면 서버·외부 연결·열린 채팅창이 모두 종료됩니다.

## 실행

현재 PC에는 필요한 패키지와 실행 바로가기가 설치되어 있습니다.

다른 PC에서 처음 설치할 경우 Node.js 22 이상을 설치한 후 `run-chat.bat`를 실행하세요. 필요한 패키지를 설치하고 서버 관리창을 엽니다. 터미널에서는 `npm ci`, `npm start`로 실행할 수도 있습니다. `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/create-shortcut.ps1`로 서버·채팅 바로가기를 만들 수 있습니다.

## 외부에서 접속하기

1. MainPC에서 **모음 서버.lnk**를 엽니다.
2. 앱이 자동으로 외부 접속 주소를 생성합니다. **서버 관리 창**에 **접속 가능**이 표시될 때까지 기다립니다.
3. **친구 초대하기**에서 주소를 복사해 상대방에게 전달합니다.
4. 상대방은 브라우저에서 주소를 열고 닉네임만 입력하고 입장합니다.

Tailscale, 계정 가입, 로그인, 공유기 포트포워딩은 필요하지 않습니다. 앱에 포함한 Cloudflare Quick Tunnel 연결 모듈이 자동으로 HTTPS 주소를 만듭니다. 첫 실행 때 모듈이 없으면 공식 배포 파일을 다운로드하고 SHA-256을 확인한 후 실행합니다. 현재 PC에는 설치되어 있습니다.

**주소는 `https://무작위이름.trycloudflare.com` 형태이며 서버를 재실행할 때마다 바뀝니다.** 채팅창만 다시 여는 경우에는 주소를 유지합니다. 사용자 선택에 따라 기존 고정 주소 조건을 변경했습니다. 주소가 생성된 뒤 실제 외부 서버 응답까지 확인해야 **접속 가능**을 표시합니다. 현재 주소는 `공유주소.txt`에도 저장됩니다. 정상 종료할 때 삭제하며, 강제 종료 후 남은 주소 파일은 다음 서버 시작 때 제거합니다.

- [Cloudflare Quick Tunnels 공식 안내](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)

MainPC가 켜져 있고 서버 관리 창이 열려 있어야 접속할 수 있습니다. 채팅창은 닫아도 됩니다. 서버 관리 창을 닫으면 서버와 외부 연결 모듈이 함께 종료됩니다. 앱 프로세스를 강제로 종료해도 IPC 연결 해제를 통해 서버와 외부 연결을 정리합니다. 연결에 실패하면 서버 관리 창의 **외부 연결 다시 시도**를 누르세요. Quick Tunnel은 가동률 보장이 없고, 동시에 처리 중인 요청은 200개로 제한됩니다.

## 사용법

- 실시간 채팅, 접속자 목록, 입력 중 표시, 자동 재접속
- PC: Enter 전송 / Shift+Enter 줄바꿈 / 한글 조합 중 Enter는 전송하지 않음
- 모바일: Enter는 줄바꿈, 오른쪽 전송 버튼으로 보내기; 입장 직후 키보드가 자동으로 열리지 않음
- `+`, 드래그 앤 드롭, 이미지 붙여넣기로 첨부
- 전송 전 미리보기·취소, 업로드 진행률, 실패 시 다시 보내기
- PNG·JPEG·GIF·WebP 이미지의 대화 내 미리보기와 확대·원본 다운로드
- MP3·MP4 등 미디어는 실제 재생 길이를 검사해 **10분 이하이면 채팅 안에서 재생·일시정지·탐색·다운로드** 가능
- 10분을 넘거나 재생 길이를 확인할 수 없는 파일은 **일반 첨부파일로 전송·다운로드**; 파일당 최대 50MB
- 새 메시지가 들어와도 재생 중인 미디어 유지, 여러 재생 버튼을 누르면 마지막으로 선택한 파일만 재생
- 다른 형식의 파일은 다운로드로 제공, 파일당 최대 50MB·한 번에 10개
- 공유 파일 패널은 최근 200개, 대화는 최근 100개부터 이전 내역을 더 불러오기
- 검색은 현재 불러온 대화·닉네임·첨부파일명에 적용
- 새 대화가 와도 읽던 위치 유지, 새 메시지 버튼으로 맨 아래 이동
- 스마트폰: 주요 조작 버튼 44px, 읽기 쉬운 메시지, 홈 표시줄·노치 여백, 화면 키보드 높이에 맞춰 유지되는 입력창
- 모바일 첨부 메뉴에서 사진 보관함·카메라 촬영·파일 선택, 전송 전 미리보기와 첨부 취소
- 멤버 메뉴와 공유 파일 패널: 닫기·바깥 영역·뒤로가기 지원, 키보드 포커스가 열린 패널 안에 유지됨
- 작은 휴대폰부터 가로 방향까지 대화 중심으로 표시, 공유 파일은 아래에서 여는 패널로 제공

## 데이터와 입장 정보

Android 앱은 [android/README.md](android/README.md)를 참고하세요. 앱의 **서버 입장** 버튼으로 MainPC의 현재 채팅방에 연결합니다. 서버 시작 때 별도 `connection` 브랜치에 접속 주소와 실행 ID만 자동 등록하므로, 재시작으로 주소가 바뀌어도 앱을 새로 설치할 필요가 없습니다. MainPC 관리창에 **Android 앱 입장 가능**이 표시된 뒤 입장하세요.

**서버를 시작할 때마다 과거 대화·첨부파일·파일 목록·복구 기록을 모두 삭제하고 새 채팅을 시작합니다.** 채팅창만 닫았다가 다시 열 때는 같은 서버의 현재 대화를 유지합니다. `.data/`는 현재 실행 중인 방의 임시 대화·파일과 입장 설정을 저장하는 위치입니다.

| 파일 | 내용 |
| --- | --- |
| `settings.json` | 방 이름 |
| `messages.jsonl` | 현재 서버 실행의 대화, 다음 서버 시작 시 초기화 |
| `uploads/`, `uploads.json` | 현재 실행의 첨부파일과 메타데이터, 다음 서버 시작 시 삭제 |
| `desktop.log` | 서버 실행·종료와 외부 접속 설정 기록 |

비밀번호 없이 닉네임만으로 입장합니다. 서버 주소로 입장한 참가자는 현재 방의 대화와 공유파일을 볼 수 있습니다. 이전 버전의 비밀번호 파일과 salt·hash는 서버 시작 시 제거합니다. 이 폴더는 Git 저장 대상에서 제외되어 있습니다. 외부 접속은 Cloudflare의 HTTPS를 사용하고, 현재 방의 데이터는 MainPC에 저장합니다. 종단간 암호화 메신저는 아닙니다.

서버를 재시작하면 브라우저 참가자는 다시 입장해야 합니다. MainPC 앱은 자동 입장합니다. 첨부파일은 임의의 ID로 저장하고, 이미지 파일 서명을 확인합니다. 실행 가능한 HTML·SVG 등을 대화 안에서 실행하지 않고 다운로드로 제공합니다.

## 검증

`npm run check`, `npm test`, `npm run test:desktop`

통합 테스트는 닉네임만으로 입장, 이전 비밀번호 설정 제거, 입장 전 접근 차단, 두 참가자 간 실시간 전송, 첨부파일 권한과 이미지 분류, 미디어 재생 길이·10분 경계·범위 요청 재생·강제 다운로드·위장 MP3 처리, 전송 재시도 중복 방지, 서버 재시작 시 대화·첨부·복구 기록 삭제, 포트 충돌 시 기존 방 보존을 확인합니다. 데스크톱 테스트는 두 창의 분리, MainPC 자동 입장, 일반·모바일 화면 가로 넘침, 채팅창 닫기·다시 열기 후 서버 유지, 서버 창 닫기와 프로세스 강제 종료 후 서버 종료를 확인합니다.

외부 연결까지 검증하려면 PowerShell에서 `$env:CHAT_TEST_TUNNEL='1'; npm run test:desktop`를 실행합니다. 분리된 테스트 데이터로 임시 외부 주소를 생성하고, 외부 HTTPS 로그인·실시간 WebSocket 메시지와 창 종료·강제 종료 후 연결 모듈 종료까지 검증합니다.

`npm run server`는 개발용 브라우저 서버 실행 명령이며 창 종료와 서버가 연결되지 않습니다. 평소에는 바로가기 또는 `npm start`를 사용하세요.
